## Notes

- **Standard match**: requires ≥2 gold keywords to appear in a retrieved chunk.
- **Lenient match**: requires ≥1 gold keyword — maximum-recall mode for safety-critical retrieval (acceptable when downstream clinical triage must not miss any potentially relevant passage).
- **BM25+Dense**: hybrid ensemble with BM25 weight=0.4, dense weight=0.6, Reciprocal Rank Fusion (RRF). Medical query expansion applied (40+ abbreviation→phrase mappings).
- Config G is the **Broad-Recall Safety Config** (k=10, lenient) — most appropriate for emergency and high-risk triage queries.
